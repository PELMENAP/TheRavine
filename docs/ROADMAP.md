# The Ravine — RoadMap механик и систем

Основание: `The_Ravine_LORE.md` (лор), `PHILOSOPHY.md`, карты `docs/map`. Состояние кода — на вершину ветки `claude/practical-mendel-c5lbxd` (коммит `60659a4`).
Сроков нет: у этапов указаны размер (S / M / L / XL) и зависимости. Этап закрыт, когда выполнены его критерии готовности.

## 1. Что из лора уже есть в коде

| Элемент лора | Состояние | Где в коде / чего не хватает |
|---|---|---|
| Пульс Времени (`SimulationClock`) | Есть | Единственный источник времени симуляции, масштаб времени в `WorldConfiguration` |
| Старение, голод, смерть агентов | Есть | `baseMaxAge`, `senescence*` в `SimulationRules`, `MortalityComponent`, `DeathCause` |
| Атрофия навыков (ΔL = −λL) | Есть | Граф навыков: `SkillGraphStore`, `SkillDecayJob`, `skillDecayRate`; у игрока тот же свод правил (`PlayerSkillGraph`), гены навыков — в `GeneticParameters` |
| Старение игрока | Нет | `PlayerEntity` проходит метаболизм и вирусологию через `CreatureCore`, но возраста у него нет |
| Круговорот биомассы (`ReturnToSoil`) | Есть, грубо | `ChunkFoodIndex`: `SoilEnergy`, `Fertility`, `Depletion` — одно значение на чанк, а не `humusMap` по клеткам; живёт только в памяти сессии |
| `compactionMap` (тропы) | Нет | Есть визуальное поле `GrassTrampleField` и канал колонии `Trail`; на движение и рост они не влияют |
| `windField` | Есть | `WindField` / `WindSampler`; ветер уже ведёт огонь |
| Эпидемии | Есть | Вирусология целиком: лента, рибосома, штаммы, приручённые сегменты (`Segment.Tamed`), канал `Sickness` |
| Времена года, пожары | Есть | `SeasonClock`, `FireEvent` — в лоре не упомянуты |
| «Кровная память» | Частично, иначе чем в лоре | Мозг один на колонию (`SharedHierarchicalBrain`), веса общие. Скрещиваются `GeneticParameters` (гиперпараметры и фенотип), а не веса |
| Любопытство (`RND`) | Есть | `RandomNetworkDistillation` |
| Речь NPC | Есть, иначе чем в лоре | Возникающий язык токенов: `SpeechBus`, `SpeechLexicon`. `LLMUnity` используется только для описаний предметов |
| `ColonyTaskBoard` | Заготовка | Направление `DirectionKind.Task` зарезервировано в интерфейсе мозга и нигде не выставляется; близкое: `ColonyPoiBoard`, каналы `ColonyChannel`; `PlayerTasks` — заготовка на 92 строки |
| Размножение агентов | Есть | `ColonyPopulation.SpawnChild`, `EvolutionService.SelectMate`, план `Court` |
| Размножение игрока, переход к потомку | Нет | `IController` — интерфейс ввода (движение, прицел), а не «контур сознания»; смерть игрока только запрещает правки мира |
| Многоуровневые здания (`BuildingVolume`) | Есть | `ObjectInfo.Levels`, предел `ObjectInfo.MaxLevels = 8`, платформы, коллизия без PhysX |
| Строительство агентами | Заготовка | Глаголы `Take` / `Put`, `EntityModel.HeldObject`, `ObjectSensor` уже есть, но `Take` по объекту мир не меняет; `WorldEdits.TryPlace` / `TryPickUp` вызывает только `PlayerController`. Нарушение равенства в пользу игрока |
| `WorldCodexService`, `LawArticle`, Lex Specialis | Нет | Опоры: снимок `SimulationRules.Frame`, `WorldState.rulesMultipliers`, кворум выбора гнезда в `ColonyState`, канал `Territory` |
| `Rive` | Есть как песочница | Целые и массивы, `get` / `send`, головоломки; к объектам мира не привязан, исполняется в клиентском терминале |
| Производственные цепочки | Нет | Только ручной крафт `CraftModel` |
| Энтропия мира | Нет | Опора: `EnergyLedger` уже считает все потоки энергии мира |
| Смерть-Жнец | Нет | Есть сущность `Mimic` (процедурные ноги), действие `EntityAction.Mimic`, `MimicPhenotype`, кольцо решений `DecisionRing` |
| `cycleCount`, «Великие Стирания» | Заготовка | Поле `WorldState.cycleCount` служит флагом первого запуска (выдача стартового инвентаря в `UIInventory`), перезапуска мира нет |
| Руины `WFC` | Заготовка | `WaveFunctionCollapseAlgorithm`, `StructureGenerator` существуют, в генерацию мира не включены |
| Чертог Наблюдателя (`WorldManagerUI`) | Есть как меню | Список миров; в `WorldState` уже есть флаг `gameWon` |
| Фракции, налоги, бунты | Нет | Есть `CurrencyComponent`, экспериментальный `Market`, территории колоний |
| Мир живёт без наблюдателя | Частично | Чанк, вернувшийся в окно, догоняет случайные тики (`catchUpBurstRounds`); агенты вне окна не живут |

## 2. Правки лора, на которых стоит RoadMap

1. **Смерть — правило, а не босс для игрока.** Любое существо, выжившее при низкой вероятности выживания, копит «долг». Долг притягивает хищника-`Mimic`, обученного подражанием на решениях должника. Параметры — в `SimulationRules`. Жнец приходит и к NPC; игрок может наблюдать чужой поединок.
2. **Награда за победу — приручённый штамм.** Долголетие — эндогенный сегмент вирусной ленты (`Segment.Tamed`), наследуемый потомками и заразный. Никакой выданной сценарием «печати».
3. **Кровная память разделена на две.** Гены (`GeneticParameters`) идут от родителей. Мозг колонии — культура: она общая и переживает отдельных существ. Потомок игрока наследует гены и место в колонии, а не «веса родителей».
4. **Сознание игрока — привязка к телу, а не `IController`.** Нужен отдельный, одинаковый для человека и ИИ-игрока механизм «внешний разум управляет телом существа». Тело — обычный агент, решение вместо мозга колонии принимает внешний источник.
5. **Энтропия локальна.** Поле по чанкам с диффузией, а не глобальный скаляр. Последствия — через существующие системы: истощение почвы, шанс возгорания, скорость мутаций штаммов, разброс генов хищников. Никакого «спавна орд».
6. **Нагрузка `Rive` — реальная энергия.** Каждая операция скрипта тянет энергию из питающего терминала; так `N_rive` в формуле становится следствием `EnergyLedger`, а не отдельным счётчиком.
7. **Вертикаль — факт мира, а не задание.** Высота тумана и стоимость подъёма материала заданы правилами. Строить может любая колония; NPC могут дойти первыми или без игрока.
8. **LLM — переводчик, а не разум NPC.** Разум — мозг колонии и возникающий язык. LLM превращает высказывания и состояние в диегетический текст для человека (по одному говорящему на колонию, с ограничением частоты). Иначе число жителей упрётся в стоимость LLM.
9. **Финал для нескольких наблюдателей.** В сетевой игре и с ИИ-игроками «Время» — все внешние разумы и хозяин мира. Отречение — флаг мира: кнопки удаления и перезапуска исчезают, внешний разум больше не получает тело с памятью; мир продолжает считаться.
10. **Термины.** В лоре «Равнина» чередуется с «лощиной»; игра — The Ravine. Номера постулатов в таблице лора не совпадают с `PHILOSOPHY.md` (там §5 — «Образ важнее объёма», «мир живёт без наблюдателя» — пункт §3).
11. **Масштаб времени.** Жизнь агента — `baseMaxAge = 1200` единиц времени симуляции. Нужно определить «год» мира и выразить `W_total` в измеримой работе (энергия, поднятая на высоту), иначе «10⁶ лет» нельзя ни проверить, ни сбалансировать.

## 3. Этапы

```
0 Фундамент ──┬─ 1 Род ───────────────┬─ 7 Долг Смерти
              ├─ 2 Живая земля ──┬────┤
              └─ 3 Стройка всех ─┼─ 4 Кодекс ─┬─ 6 Энтропия ─┬─ 8 Город ── 9 Небо
                                 └─ 5 Машины ─┘              │
                                    A Речь и перевод (после 1) ┘
```

### Этап 0. Фундамент: память мира и равенство — M

Цель: мир, который переживает сессию и одинаков для всех.

- Сохранять почву, трупы, заразные грузы и табу `ChunkFoodIndex` вместе с чанками (`ChunkStore`, новая версия файла).
- Репликация правок мира и огня всем клиентам (находка аудита 27, открытые вопросы `docs/map/map-events.md`).
- Устойчивая личность игрока (`OwnerClientId`), сохранение чужих инвентарей на хосте.
- `cycleCount` перестаёт быть флагом первого запуска: стартовый инвентарь получает свой признак.
- Лор — в репозиторий (`docs/LORE.md`), с правками раздела 2.

Готово, когда: мир после перезагрузки имеет ту же почву и трупы; второй клиент видит правки и огонь первого.

### Этап 1. Род: смерть, наследование, смена тела — L

Зависит от: 0.

- Возраст и старение игрока по тем же `baseMaxAge` / `senescence*`, что у агентов (через `CreatureCore`).
- Игрок размножается тем же правилом, что агент: согласие партнёра решает его мозг (план `Court`, сытость, ценность для гнезда), а не кнопка.
- Привязка внешнего разума к телу: один механизм для человека и ИИ-игрока; после смерти — выбор живого потомка, без потомков — конец рода (новое существо без наследства).
- Игрок состоит в колонии: вносит вклад в каналы и общий мозг наравне с остальными.
- Потомок получает гены навыков родителей (`SkillOriginX/Y`, `Plast*`) тем же `Crossover`; уровни навыков не наследуются — их стирает Время.

Готово, когда: игрок умирает от старости, продолжает потомком с унаследованными генами; тест равенства — одно и то же правило размножения проходит для агента и для игрока.
Внимание: изменение размера входов или каталога действий — увеличить `SharedBrainSnapshot.Version`.

### Этап 2. Живая земля: перегной и тропы — M

Зависит от: 0.

- Уплотнение почвы: поле по чанку с грубой сеткой, пишется тем же `StampCreature`, что и вытаптывание травы; влияет на скорость движения, рост NAL и плодородие.
- Перегной тоньше чанка: грубая сетка внутри чанка вместо одного `SoilEnergy`; трупы и органика удобряют место, где лежат.
- Оба поля сохраняются, читаются шейдером травы через существующий `SoilShaderFeed`.

Готово, когда: дорога между гнездом и кормом появляется сама и ускоряет ход всем; на месте массовой гибели растёт больше.
Стоимость тика не должна зависеть от числа существ (см. `docs/OPTIMIZATION.md`).

### Этап 3. Строят все: правки мира агентами и доска задач — L

Зависит от: 0. Усиливается этапом 2.

- Глаголы агента `Take` и `Put` с направлением `Object` начинают менять мир через тот же `WorldEdits`, с теми же проверками досягаемости и запаса, что у игрока; `HeldObject` заполняется.
- Гнездо как постройка: склад, укрытие, тепло (`WarmthField`) зависят от поставленных объектов.
- `ColonyTaskBoard` как расширение `ColonyPoiBoard`: запись «где, что нужно, чем подкреплено». Писать может любое существо. Запись выставляет зарезервированное направление `DirectionKind.Task` и даёт подкрепление за выполнение; это не приказ.
- Чертёж — объект мира: ставится существом, виден всем, превращается в стройку по мере подноса материалов.

Готово, когда: колония без игрока возводит укрытие к зиме; игрок через доску меняет распределение труда, не имея ни одной команды «иди».
Внимание: глаголы и направление уже входят в интерфейс мозга v11; версия снимка растёт, только если добавятся входы.

### Этап 4. Скрижали Договора: `WorldCodexService` — L

Зависит от: 3.

- `LawArticle` — данные: поле `RulesFrame`, множитель в жёстких пределах, область действия (территория колонии по каналу `Territory`), срок.
- Принятие — кворумом колонии (механизм уже есть для выбора гнезда); игрок голосует как один житель.
- Lex Specialis: местная статья перекрывает общую на своей территории.
- Цена статьи: отклонение от базовых правил копит `D_codex` (вход этапа 6) и требует энергии на поддержание.
- Сервер — источник истины; пределы множителей проверяются при загрузке и при принятии (`docs/SECURITY.md`).

Готово, когда: две колонии живут по разным правилам на своих территориях; колония NPC сама принимает статью; чтение правил в тике остаётся без аллокаций.

### Этап 5. Язык Шестерён: терминалы и машины в мире — XL

Зависит от: 3.

- Терминал и машина — объекты мира (`ObjectInfo`) с портами; `get` / `send` языка `Rive` привязаны к портам соседних объектов.
- Скрипты машин исполняются на сервере, в том же бюджете операций; операции стоят энергии (пункт 2.6).
- Переработка: рецепты `CraftModel.Shared` исполняются машиной так же, как руками; конвейер — перенос между портами.
- Доступ к терминалу — физический и равный: агент может запускать и менять программы (минимум — выбор из готовых).

Готово, когда: цепочка из трёх машин перерабатывает ресурс без участия существ и останавливается без энергии; нагрузочный тест бюджета `Rive` на сервере пройден.
Внимание: сначала прочитать `docs/SECURITY.md` раздел 8; скрипт — ввод от постороннего.

### Этап 6. Пепел Спешки: энтропия — L

Зависит от: 4, 5; использует 2.

- Поле энтропии по чанкам: источники — работа машин, операции `Rive`, отклонение Кодекса; стоки — живая биомасса (NAL, трава, грибница, лес) и перегной; диффузия к соседям и по ветру.
- Коэффициенты α, β, γ и ёмкости стоков — в `SimulationRules`; учёт — новые статьи `EnergyLedger`.
- Последствия только через существующие системы: `Depletion` почвы, шанс возгорания, скорость мутаций штаммов, разброс генов, стресс в гомеостазе.
- Диагностика: колонки в `docs/simulation_log.md`, слой в `SimulationDebugDashboard`, проявление в шейдере травы.

Готово, когда: город без зелени деградирует, такой же город в лесу живёт; формула баланса сходится по `EnergyLedger`.

### Этап 7. Долг Смерти — M

Зависит от: 1.

- Долг: оценка «должен был умереть» из уже имеющихся величин (здоровье у нуля, проигранный бой, голод); копится и затухает.
- Жнец: `Mimic`, чья политика получена подражанием решениям должника из `DecisionRing`; для игрока — из его записанных действий.
- Приручённый штамм долголетия у победителя; защита статьёй Кодекса — после этапа 4.

Готово, когда: Жнец приходит к агенту без участия игрока; поединок исполняется обычными правилами боя; все пороги — в `SimulationRules`.

### Этап 8. Город: жизнь вне взгляда и двойной масштаб — XL

Зависит от: 3, 5, 6.

- Макросимуляция далёких чанков: численность, запасы, энтропия колонии считаются агрегатами, пока рядом нет наблюдателя; при подходе — разворачиваются в агентов.
- Снятие предела `ObjectInfo.MaxLevels = 8` для высотных построек либо «этажи» как отдельные слои чанка.
- Экономика из того, что есть: `CurrencyComponent`, обмен, склады; налог и собственность — статьи Кодекса, фракции — колонии с разными скрижалями.
- Макро-инструменты игрока — чертежи и доска (этап 3), доступные из тела, без камеры-духа.

Готово, когда: поселение из сотен жителей переживает уход игрока на несколько поколений и меняется за это время.

### Этап 9. Небо: Вертикаль, циклы и Отречение — L

Зависит от: 8.

- Туман как слой мира с высотой; подъём материала стоит работы, сумма и есть `W_total`.
- Великие Стирания: перезапуск мира увеличивает `cycleCount` и оставляет слепок города; `StructureGenerator` (`WFC`) строит из него руины следующего цикла.
- Выход сквозь туман — переход к сцене меню: тот же утёс, тот же `WorldManagerUI`; жители читают журнал мира (`RavineLogger`, `WorldState`).
- Отречение: директива в корневом терминале ставит флаг мира (`gameWon` или новый), убирает удаление и перезапуск, отвязывает внешний разум; мир продолжает считаться макросимуляцией.

Готово, когда: мир после Отречения можно открыть только наблюдателем или новым смертным без памяти рода; колония NPC способна достроить Вертикаль без игрока.

### Сквозной поток A. Речь и перевод — M, параллельно с 1–6

- Метрики возникающего языка уже есть (`SpeechMetrics`); добавить словарь «токен → смысл» по наблюдаемой корреляции с действиями.
- LLM-переводчик поверх словаря: текст для человека, по правилам `docs/SECURITY.md` раздел 11 (вывод — недоверенный текст, никогда не команда).
- Диегетический словарь раздела 5 лора — в подписи `SpeechLabelFeed`, тексты терминала и описания предметов.

## 4. Порядок, если нужно выбрать ближайшее

1. Этап 0 — без сохранения почвы и репликации остальное нельзя проверить.
2. Этап 3 (минимум: `Take` / `Put` агента меняют мир) — интерфейс мозга уже готов; устраняет найденное преимущество игрока.
3. Этап 1 — даёт первый «акт» лора: смертность и род.
4. Этап 2 — дешёвый и сразу видимый: тропы и перегной.
5. Дальше 4 → 5 → 6; этап 7 — в любой момент после 1.

## 5. Риски

| Риск | Чем закрывается |
|---|---|
| Версия мозга растёт при новых входах (этапы 1, 6) — сохранённые мозги теряются | Собрать изменения входов в одно повышение версии на этап |
| `Rive` на сервере — поверхность атаки | Бюджет на запуск уже есть; добавить бюджет на игрока и на чанк, тесты до выпуска |
